# fe-crypto

**Features**
- Groth16 Verifier
- BN254 Pairing Friendly Elliptic Curve
- Precompile Pairing Function

This repo is a **Fe v2 workspace** with two ingots:
- `crypto` (BN254 precompile wrappers)
- `verifiers` (Groth16 BN254 verifier)

Quick checks:
- `fe check .`
- `fe test ./crypto`
- `fe test ./verifiers`
